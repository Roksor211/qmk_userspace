# wireless_clone_mac

QMK port of the `280Zo/charybdis-wireless-mini-zmk-firmware` QWERTY layout for the wired Charybdis `4x6`.

Notable adaptations:

- The additional top row is filled with a standard US number row (`\`` through `0`) plus `Backspace`.
- The additional lower thumb keys are intentionally left unassigned.
- Scroll mode and slow/sniping mode are exposed from the left thumb tap dance.
- The top-right key keeps the original layer-switch idea: tap for base, hold for extras, double tap for game.
